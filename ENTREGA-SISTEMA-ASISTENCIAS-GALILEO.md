## 1. DESCRIPCIÓN DEL SISTEMA

El sistema **"Asistencias Galileo"** es una aplicación de escritorio diseñada para gestionar el control de asistencia del personal y/o estudiantes mediante la integración con dispositivos biométricos de huella digital (ZK-teco).

---

## 2. FUNCIONALIDADES INCLUIDAS

El sistema entregado contempla las siguientes funcionalidades:

### 2.1 Panel Principal (Dashboard)
- Estadísticas en tiempo real de asistencias del día
- Visualización de tendencias semanales
- Listados de llegadas tempranas y tardías
- Barras de progreso de asistencia

### 2.2 Gestión de Asistencias
- Registro detallado de todas las marcaciones
- Filtros por día, semana o historial completo
- Cálculo automático de horas trabajadas
- Identificación automática de entradas y salidas

### 2.3 Gestión de Usuarios
- Lista completa de usuarios registrados
- Historial individual por persona
- Resumen diario de asistencia por usuario
- Estadísticas de asistencia personalizadas

### 2.4 Reportes
- Generación de reportes por rango de fechas
- Exportación para impresión
- Resúmenes diarios por usuario

### 2.5 Configuración
- Configuración de horarios de trabajo
- Definición de tolerancias para tardanzas
- Reglas de asistencia personalizables

### 2.6 Sincronización con Dispositivo Biométrico
- Conexión automática con lector de huella ZK-teco
- Extracción de registros de asistencia
- Creación y eliminación de usuarios en el dispositivo
- Enrolamiento de huellas digitales

---

## 3. COMPONENTES TECNICOS

El sistema se compone de los siguientes módulos:

| Componente | Descripción |
|------------|-------------|
| **Aplicación de Escritorio** | Interfaz gráfica desarrollada con Electron.js que integra todo el sistema |
| **Servidor Backend** | API REST desarrollada con Node.js y Express para procesar la lógica de negocio |
| **Frontend Web** | Interfaz de usuario desarrollada con React.js y estilos Tailwind CSS |
| **Base de Datos** | Almacenamiento en tiempo real mediante Supabase (PostgreSQL) |

## 5. REQUERIMIENTOS TÉCNICOS

Para el funcionamiento del sistema se requiere:

- Windows 10 o superior (64 bits)
- Dispositivo biométrico ZK-teco conectado a la red local
- Conexión a Internet (para sincronización con la base de datos en la nube)
- Node.js instalado en el servidor (modo desarrollo)
